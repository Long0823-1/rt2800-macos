RT2800 Wi-Fi

Installs a Wi-Fi driver (user-space daemon) and a menu bar app for USB Wi-Fi adapters with the Ralink RT5592 chip (Buffalo, USB 0411:0253).

  • A background daemon (rt2800d)
  • The menu bar app “RT2800 Wi-Fi” (status, network list, connect, auto-connect)
  • The rt2800-wifi command

Supports 2.4 GHz and 5 GHz, WPA2-PSK and open networks. Traffic goes through a dedicated network interface (utun) and does not appear in the macOS Wi-Fi settings.

Experimental software. For Intel Macs (x86_64). Plug the adapter in before use. The rt2870.bin firmware (Ralink / MediaTek) is included.
